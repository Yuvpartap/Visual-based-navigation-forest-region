# ============================================================================
# INSTALLATION INSTRUCTIONS FOR WINDOWS
# ============================================================================

# Step 1: Install Python
# Download Python 3.8+ from: https://www.python.org/downloads/
# During installation:
# - Check "Add Python to PATH"
# - Check "Install pip"

# Step 2: Install CUDA Toolkit (for GPU support - REQUIRED for good performance)
# Download CUDA 11.8 or 12.1 from:
# https://developer.nvidia.com/cuda-downloads
# 
# For CUDA 11.8:
# https://developer.nvidia.com/cuda-11-8-0-download-archive
#
# For CUDA 12.1:
# https://developer.nvidia.com/cuda-12-1-0-download-archive
#
# Install with default settings
# Restart computer after installation

# Step 3: Install cuDNN (NVIDIA Deep Neural Network library)
# Download from: https://developer.nvidia.com/cudnn
# Extract and copy files to CUDA installation directory:
# - Copy bin\*.dll to C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.8\bin
# - Copy include\*.h to C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.8\include
# - Copy lib\*.lib to C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.8\lib\x64

# Step 4: Install Visual Studio Build Tools (required for some packages)
# Download from: https://visualstudio.microsoft.com/downloads/
# Install "Desktop development with C++" workload

# Step 5: Create virtual environment (recommended)
# Open Command Prompt or PowerShell:
# python -m venv venv
# venv\Scripts\activate

# Step 6: Upgrade pip
# python -m pip install --upgrade pip setuptools wheel

# Step 7: Install PyTorch with CUDA support
# For CUDA 11.8:
# pip install torch==2.1.0 torchvision==0.16.0 --index-url https://download.pytorch.org/whl/cu118

# For CUDA 12.1:
# pip install torch==2.1.0 torchvision==0.16.0 --index-url https://download.pytorch.org/whl/cu121

# For CPU only (NOT RECOMMENDED - very slow):
# pip install torch==2.1.0 torchvision==0.16.0

# Step 8: Install remaining packages
# pip install -r requirements-windows.txt

# Step 9: Install ffmpeg (optional, for video compression)
# Download from: https://ffmpeg.org/download.html
# Extract to C:\ffmpeg
# Add C:\ffmpeg\bin to System PATH environment variable

# ============================================================================
# TROUBLESHOOTING
# ============================================================================

# Issue: "CUDA not available" or "torch.cuda.is_available() returns False"
# Solutions:
# 1. Verify NVIDIA GPU driver is installed:
#    Open Device Manager -> Display adapters -> Check for NVIDIA GPU
# 2. Update GPU driver from: https://www.nvidia.com/Download/index.aspx
# 3. Reinstall CUDA Toolkit
# 4. Reinstall PyTorch with correct CUDA version:
#    pip uninstall torch torchvision
#    pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118

# Issue: "CUDA out of memory"
# Solutions:
# 1. Close other GPU-intensive applications
# 2. Reduce grid_size in config (e.g., from 7 to 5)
# 3. Reduce resize_max (e.g., from 840 to 640)
# 4. Reduce tile_cache_items (e.g., from 128 to 64)

# Issue: "DLL load failed" or "ImportError"
# Solutions:
# 1. Install Visual C++ Redistributable:
#    https://aka.ms/vs/17/release/vc_redist.x64.exe
# 2. Ensure CUDA bin directory is in PATH:
#    C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.8\bin
# 3. Restart computer after installing CUDA/cuDNN

# Issue: "No module named 'kornia'"
# Solution:
# pip install kornia kornia-rs

# Issue: OpenCV video codec errors
# Solutions:
# 1. Install K-Lite Codec Pack: https://codecguide.com/download_kl.htm
# 2. Install ffmpeg (see Step 9 above)

# Issue: Slow processing on CPU
# Solution:
# Install CUDA and GPU-enabled PyTorch (see Steps 2-7 above)

# Issue: "Access denied" during pip install
# Solutions:
# 1. Run Command Prompt as Administrator
# 2. Use --user flag: pip install --user -r requirements-windows.txt

# Issue: Path too long errors
# Solution:
# Enable long paths in Windows:
# 1. Open Registry Editor (regedit)
# 2. Navigate to: HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\FileSystem
# 3. Set LongPathsEnabled to 1
# 4. Restart computer

# ============================================================================
# PERFORMANCE OPTIMIZATION
# ============================================================================

# For NVIDIA GPUs:
# 1. Ensure GPU drivers are up to date
# 2. Use CUDA 11.8 or 12.1 for best compatibility
# 3. Enable TF32 for faster computation (enabled by default in code)
# 4. Close background applications to free GPU memory
# 5. Use NVIDIA Control Panel to set "Prefer maximum performance"

# For better video encoding:
# 1. Install ffmpeg (see Step 9)
# 2. Use H.264 codec for smaller file sizes
# 3. Adjust CRF value in code (lower = better quality, larger file)

# Windows Power Settings:
# 1. Set power plan to "High Performance"
# 2. Disable USB selective suspend
# 3. Disable hard disk sleep
