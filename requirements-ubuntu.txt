# ============================================================================
# TROUBLESHOOTING
# ============================================================================

# Issue: "CUDA out of memory"
# Solution: Reduce grid_size in config (e.g., from 7 to 5)
#           Reduce resize_max (e.g., from 840 to 640)

# Issue: "libcudnn.so not found"
# Solution: Install cuDNN:
#           sudo apt-get install libcudnn8 libcudnn8-dev

# Issue: "No module named 'kornia'"
# Solution: pip install kornia kornia-rs

# Issue: OpenCV video codec errors
# Solution: sudo apt-get install -y libavcodec-dev libavformat-dev libswscale-dev

# Issue: Slow processing on CPU
# Solution: Install CUDA and GPU-enabled PyTorch (see Step 5 above)
